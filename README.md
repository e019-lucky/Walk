# 현실판 Paper.io · 걸어서 땅따먹기

지도 위를 실제로 걸어다니며 내 영역을 넓히는 위치 기반 게임입니다.
GPS로 이동하면 이동 궤적이 그려지고, 다시 내 영역 안으로 들어오면 그 사이가 내 땅이 됩니다.

## 바로 플레이

https://e019-lucky.github.io/geo-paper-io/

휴대폰 브라우저에서 열고, 위치 권한을 허용한 뒤 걸어다니면 됩니다.
실내에서는 화면 오른쪽 위 **GPS 모드** 버튼을 눌러 **테스트 패드**로 바꾸면
지도를 탭해서 이동하거나 방향 패드로 이동하며 게임을 연습할 수 있습니다.

## 조작

| 요소 | 설명 |
| --- | --- |
| 점령 면적 / 점령 횟수 | 현재 내 영역의 넓이와 점령 성공 횟수 |
| GPS 모드 / 테스트 패드 | 실제 위치로 걷기 ↔ 가상 이동 패드 |
| 내 위치 | 지도를 내 위치로 다시 맞춤 |
| 초기화 | 지금 위치에 반경 35m 새 기지를 만들고 기록을 0으로 |
| 방향 패드 (테스트 패드에서만) | 8방향 이동, 가운데 버튼은 정지 |

## 게임 규칙

1. 시작하면 현재 위치에 반경 35m의 기지가 생깁니다.
2. 기지 밖으로 나가면 이동 궤적이 점선으로 그려집니다.
3. 다시 내 영역 안으로 들어오면 궤적이 영역과 합쳐지고 `+XXX m² 점령!` 이 표시됩니다.
4. 영역과 기록은 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.

## 구조

- `index.html` — 화면 마크업, Leaflet / Turf.js CDN 로드
- `assets/style.css` — 모바일 우선 다크 UI (safe-area 대응, 가로 스크롤 없음)
- `assets/app.js` — 지도·GPS·궤적 점령 로직
- 빌드 단계 없음: GitHub Pages가 `main` 루트를 그대로 서빙합니다.

## 기술 메모

- 지도: Leaflet 1.9.4 + CARTO Voyager 타일 (© OpenStreetMap, © CARTO)
- 계산: Turf.js 7 — `turf.area`, `turf.union`, `turf.booleanPointInPolygon`, `turf.buffer`, `turf.circle`
- 궤적 점령은 ① 궤적을 닫은 다각형과의 합집합 → ② 자기 교차·변칙 궤적에서는 궤적을 얇은 띠(buffer)로 만들어 합집합 순으로 시도하고,
  결과가 기존 영역보다 줄거나 비정상적으로 커지면 버려서 영역이 깨지지 않게 했습니다.
- GPS 정확도(accuracy)가 45m보다 나쁜 측정값은 궤적에 반영하지 않고, 1.2m 미만의 떨림은 무시합니다.
- `?debug=1` 로 열면 콘솔에서 `geoDebug.path([[lat,lng],...])` 같은 테스트 도구를 쓸 수 있습니다.
