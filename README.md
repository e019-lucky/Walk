# 폴란드볼 고 · 칸 점령 땅따먹기

지도 위에서 **칸을 콕 눌러 점령**하는 캐주얼 영토 게임입니다.
Paper.io식 궤적/영역 닫기 규칙은 없어졌고, 대신 **점령 코인**으로 한 칸씩 땅을 넓힙니다.

## 바로 플레이

https://e019-lucky.github.io/Walk/

휴대폰 브라우저에서 열면 됩니다. 실내라면 **GPS 모드** 버튼을 눌러 **테스트 패드**로 바꾸세요.

## 게임 방법

1. 내 나라볼(캐릭터)을 고릅니다. 🇰🇷 🇵🇱 🇺🇸 🇯🇵 🇬🇧 🇩🇪 🇫🇷 중 7종.
2. 반경 200m 안의 칸이 점선으로 반짝입니다. 그 칸을 **탭**하면 **코인 1개**를 써서 내 땅이 됩니다.
3. 코인은 이렇게 모읍니다.
   - **40m 걸을 때마다 +1** (상단 진행 바)
   - 지도에 떨어진 **코인 드롭 +2** (가까이 가면 자동, 눌러도 획득)
   - 코인이 10개 미만이면 **30초마다 +1** 자동 회복
4. 점령한 칸은 고른 나라의 색으로 칠해집니다. 캐릭터를 바꾸면 색도 함께 바뀝니다.

## 조작

| 요소 | 설명 |
| --- | --- |
| 점령 코인 / 점령 칸 | 지금 코인 수와 점령한 칸 수 |
| 캐릭터(오른쪽 위) | 나라볼 선택 시트 열기 |
| GPS 모드 / 테스트 패드 | 실제 위치로 걷기 ↔ 가상 이동 |
| 내 위치 | 지도를 캐릭터 위치로 다시 맞춤 |
| 도움말 | 규칙 다시 보기 |
| 초기화 | 점령 칸·코인·기록을 모두 지우고 코인 10개로 새로 시작 |
| 방향 패드 (테스트 패드에서만) | 8방향 이동, 가운데 버튼은 정지 |

테스트 패드에서 **점령 범위 밖 칸을 탭**하면 그 칸 쪽으로 캐릭터가 걸어갑니다.

## 구조

- `index.html` — 화면 마크업, Leaflet CDN 로드
- `assets/style.css` — 모바일 우선 다크 글래스 UI (safe-area 대응)
- `assets/app.js` — 칸 격자·점령·코인·나라볼 SVG 렌더링
- 빌드 단계 없음: GitHub Pages가 `main` 루트를 그대로 서빙합니다.

## 기술 메모

- 지도: Leaflet 1.9.4 + **OpenStreetMap** 타일 (`tile.openstreetmap.org`), 타일 팬에 옅은 채도/대비 필터를 걸어 칸이 잘 보이게 했습니다.
- 칸 격자: 웹 메르카토르 미터 좌표에 **80m 고정 격자**(서울 위도 ≈ 63m 칸)로 스냅해서, 지도를 아무리 움직여도 칸이 밀리지 않습니다.
- 격자는 Leaflet `overlayPane`의 캔버스 두 장(격자 / 이펙트)에 직접 그립니다. 확대 애니메이션 중에는 캔버스를 같은 배율로 변환해 타일과 어긋나지 않습니다.
- 캐릭터는 외부 이미지 없이 **인라인 SVG 나라볼**(태극기·폴란드·성조기·일장기·유니언잭·독일·프랑스)로 그려 404 위험이 없습니다.
- 저장: `localStorage` 키 `walk_polandball_v1` (점령 칸, 코인, 캐릭터, 모드, 위치). 이전 Paper.io 버전 키(`realpaperio.v1`)와 분리되어 있습니다.
- 위치는 기기 안에서만 쓰고 서버로 보내지 않습니다.
